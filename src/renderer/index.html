ParallelRoom v—
多直播间并行观看 · 录制 · 剪辑，一个号盯一整排房间
由 奕霖工作室 开发

一个自用的 Windows 桌面工具：同一个账号同时进多个抖音 / 虎牙直播间，边看边把想留的片段录下来， 录完直接在同一个程序里对齐、剪片头、加背景音、合并导出成片 —— 不用在「浏览器 / 录屏软件 / 剪辑软件」之间倒腾文件。 抓的是直播流本身（不是录屏），所以画质无损、不占显卡；ffmpeg 随包，装完就能用。

功能一览

观看

  • 多房间同屏，共享同一登录态（隐私模式，互不串号）
  • 布局：均分网格 / 中间大 · 右侧小窗 / 单间放大 / 全屏；瓦片可拖动换位并记住顺序
  • 每间独立：静音、音量、画质（超清 / 高清 / 标清）、只看画面（纯净模式）
  • 弹幕面板 / 礼物 / 页面画质徽标（页面档位 · 实际分辨率）

监控（谁在播）

  • 把直播间地址丢进列表，按优先级轮转探测，避免频繁请求被验证码拦
  • ★ 特别关注：探测更高频，列表里也永远排在最前面
  • 只看特别关注 / 搜索过滤 / 在播一键开成瓦片

录制

  • 直接抓流分段落盘再合并成 mp4（不是录屏，画质无损）
  • 分段时长可调、录制中可拆段、断流自动重连、异常退出后重启自动补成片
  • 录制中一键截「最近 N 秒」精彩片段；另有整窗录制
  • 磁盘保护：剩余空间不足自动停止

剪辑

  • 多路对齐预览 → 标定 → 画中画拼接导出
  • 图片片头（多段文字 / 字体 / 拖动排版 / 存模板 / 导出 PNG）+ 视频合并 + 背景音，一次编码出成片
  • 逐段裁剪、参与合成、原声音量；水印 / 遮罩 / 马赛克
  • 精彩片段管理：列表、按时间戳排序、全屏细剪

虚拟人 / 虚拟演播室

  • 全 CG 3D 角色 + 6 机位实时切镜头（不需要摄像头或绿幕）
  • 摄像头绿幕抠像 + 三维场景合成，可当直播画面源

兼容与体积

  • 支持抖音（live.douyin.com）、虎牙（www.huya.com）、以及本地视频 / 摄像头当瓦片
  • 绿色版解压即用：不写注册表、不需要管理员，数据跟着文件夹走
